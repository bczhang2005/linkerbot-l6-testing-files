# 石头剪刀布游戏 · 快速启动（环境已就绪）

> 前提：Go、linkerbot、PCAN 驱动、RealSense SDK、OBS、Python 依赖均已安装；L6 左手与 D405 已接好。
>
> 以下命令均假设终端当前目录为**项目根目录**（包含 `testing/` 等子文件夹的目录；游戏项目位于 `testing/dexterous/` 下）。

---

## 一、启动前

- [ ] L6 灵巧手 **24V 上电**
- [ ] **关闭** PCAN-View、RealSense Viewer 等占用程序
- [ ] 需要 4 个窗口：OBS + 3 个 PowerShell

---

## 二、按顺序执行（4 步 + 浏览器）

### ① OBS — 开虚拟摄像头

1. 打开 **OBS Studio**
2. 窗口 **右下角「控制按钮」** → 点 **「开始虚拟摄像机」**
  （若已是「停止虚拟摄像机」，说明已开，跳过）

---

### ② 终端 A — RealSense 彩色 → 虚拟摄像头

```powershell
cd testing/vision
python realsense_virtual_cam.py
```

看到 `虚拟摄像头已就绪: OBS Virtual Camera` 后 **不要关窗口**。

---

### ③ 终端 B — L6 灵巧手桥接

```powershell
conda activate linkerbot
cd testing/vision
python windows_l6_bridge.py
```

看到 `L6 已连接` 和 `Windows L6 桥接已启动` 后 **不要关窗口**。

---



### ④ 终端 C — 游戏服务

```powershell
cd testing\dexterous\dexterous-hand-rps
go run server.go -port 8899 -model l6
```

看到 `监听地址: http://localhost:8899` 后 **不要关窗口**。

---



### ⑤ 浏览器 — 开始玩

1. 打开：**[http://localhost:8899/6.gameplay/](http://localhost:8899/6.gameplay/)**
2. **摄像头** 下拉框选 **「OBS Virtual Camera」**（不要选 RealSense Depth）
3. 点 **启动摄像头** → 允许权限
4. 确认画面 **彩色**，「检测到的手」举手时为 **1**
5. 点 **开始游戏**

---



## 三、摄像头怎么选


| 选项                          | 是否选用           |
| --------------------------- | -------------- |
| **OBS Virtual Camera**      | ✅ 选这个（D405 彩色） |
| Intel RealSense … **Depth** | ❌ 黑白，无法识别      |
| Integrated Camera           | 可用，但不是 D405    |


---



## 四、结束

各终端 **Ctrl+C** 退出；OBS 里可点「停止虚拟摄像机」。

---



## 五、出问题时先看这里


| 现象      | 检查                                |
| ------- | --------------------------------- |
| 画面黑白    | 是否选了 OBS Virtual Camera；终端 A 是否在跑 |
| 检测不到手   | 同上 + 光线、手是否入镜                     |
| 手不动     | 终端 B、C 是否在跑；PCAN-View 是否已关        |
| 虚拟摄像头报错 | OBS 是否已「开始虚拟摄像机」                  |


详细说明见 **docs/石头剪刀布游戏-Windows完整指南.md**。
